# Black Hole Patience

## Problem Description

**Black Hole** is a solitaire card game (patience) played with a standard 52-card deck. The goal is to move every card from the tableau onto a single central pile called the _black hole_, one card at a time, until no cards remain.

The game is set up as follows:

- The **Ace of Spades** sits alone on the black hole pile at the start.
- The remaining 51 cards are dealt face-up into **17 piles of 3 cards** each.

A card may be moved onto the black hole pile only if its **rank** is exactly one higher or one lower than the card currently on top of the black hole (suit does not matter). Ranks wrap around, so an Ace is adjacent to both a Two and a King. Only the **top card** of each pile is available to play at any time; the cards beneath it are blocked until the one above is removed.

The question being answered is: **does a winning order exist?** This is a decision (satisfaction) problem — there is no optimisation objective.

## Model Variables

| Variable | Type        | Meaning                                                                   |
| -------- | ----------- | ------------------------------------------------------------------------- |
| `x[i]`   | `var 1..52` | The card played at step `i` in the sequence (card 1 is the Ace of Spades) |
| `y[c]`   | `var 1..52` | The step at which card `c` is played (the positional inverse of `x`)      |

Cards are numbered 1–52. The cards within each suit are numbered consecutively, and cards of the same rank across suits are 13 apart (e.g., card 1, 14, 27, and 40 are all Aces). The exact numbering is implicit in the `neighbours` table embedded in the model.

## Parameters

| Parameter      | Meaning                                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `layout[i, j]` | The `j`-th card (from top) in pile `i`; card at position `j=1` is on top, `j=3` is at the bottom                                      |
| `neighbours`   | A pre-computed table of all valid consecutive card pairs — pairs of cards whose ranks differ by exactly 1 (with Ace–King wrap-around) |

## Constraints

1. **Starting card** — The Ace of Spades (card 1) must be the first card placed, since it is already on the black hole.
2. **Rank adjacency** — Each successive card in the sequence must have a rank one higher or one lower than the previous card. This is enforced using a `table` constraint against the pre-computed `neighbours` table.
3. **Linking `x` and `y`** — The `inverse` global constraint ensures that `y` is exactly the position-to-card inverse of `x` (i.e., `x[y[c]] = c` for all cards `c`).
4. **Pile order** — Within each pile, a card can only be played _after_ all cards above it have already been played. Specifically, if card `a` sits on top of card `b` in a pile, then `y[a] < y[b]`.

## Objective

This is a **satisfaction** problem. The solver looks for any assignment to `x` (a valid playing order) that satisfies all the constraints above. There is no cost or score to optimise.
